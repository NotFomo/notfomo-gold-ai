# NOTFOMO GOLD AI

Первая статическая версия сайта для публикации на Vercel.

## Запуск локально
Откройте `index.html` в браузере.

## Публикация на Vercel
1. Создайте GitHub-репозиторий и загрузите в него `index.html` и `vercel.json`.
2. Войдите в Vercel и выберите Add New → Project.
3. Импортируйте репозиторий.
4. Для этой статической версии оставьте Framework Preset = Other, Build Command пустой, Output Directory = `.`.
5. Нажмите Deploy.

## Что уже работает
- Адаптивный интерфейс.
- Переключение вкладок календарь / новости / история.
- Явное обозначение отсутствующих live-данных.
- Панель AI-анализа и торгового плана.

## Что нужно подключить для реальных данных
- API котировок XAU/USD и, желательно, DXY и US10Y.
- API экономического календаря.
- Источник финансовых новостей.
- Backend/API route для AI-анализа и безопасного хранения ключей.

Не вставляйте секретные API-ключи в `index.html` или публичный GitHub-репозиторий. Их следует хранить в Vercel Environment Variables и вызывать через серверные функции.
